The sessions

Eight sessions, two tracks

Click a session to see what it covers.

01Zoom A · Exploration ZoomIntermediate2h
  • How leading teams work with AI — the industry standard in plain terms
  • Why context gets lost between tools, and the fix: files as shared memory (live demo)
  • What a skill is, and when to use one instead of a prompt
  • Breaking a complex task into small steps — meeting → decisions → spec → stories → Jira
  • Discussion: where do you lose context today? (feeds the workshop design)
02Zoom B · Exploration ZoomAdvanced2h
  • The standard for building agents: one job, clear trigger, job-brief instructions, minimal tools
  • Patterns: steps with human gates, maker vs checker with a stop rule, testing your agent
  • First look at agents that communicate through files (writer → critic → publisher demo)
  • Live review: volunteers' own agents checked against the standard
  • Capture projects, level and access gaps for the half-days
03Half-day 1 · Set up and break it down In personIntermediate5h
  • Create an initiative folder for your own project; convert sources to markdown
  • M365 Copilot: meeting → decisions, Researcher / Notebook brief written back to files
  • Break your task into steps; run a provided skill for each step in VS Code
  • Apply it to your own project + write-back ritual (STATE, decisions)
  • Practice assignment for the week
04Half-day 1 · Build to the standard In personAdvanced5h
  • Layered instructions + initiative folder for your project
  • Turn a repeated task into a prompt file and a skill with an example
  • Build a custom agent with a clear description and only the tools it needs
  • Test it: 3 golden inputs + should / shouldn't-trigger checks
  • Apply it to your own project
05Half-day 2 · From project to Jira In personIntermediate5h
  • Show & tell from the practice week
  • Write stories with provided skills → critic agent → fix
  • Atlassian MCP: dry-run → approve → create epic and stories in sandbox Jira
  • Internal speakers: AT&T Jira setup and internal agents (FYI)
  • Write your first own skill · personal "which tool, when" card
06Half-day 2 · Agents that communicate with files In personAdvanced5h
  • Show & tell from the practice week
  • Chain writer → critic → publisher using hand-off files and human gates
  • Critic loop with a stop rule; fixed rules as a checklist, judgment for the AI
  • Publish to Jira via MCP with dry-run and approval
  • Agent design canvas for one real AT&T workflow · version your kit
07Clinic ZoomIntermediate1h
  • Bring a real workflow — reviewed live
  • Fix what's blocking adoption
  • Share wins in the Teams channel
08Clinic ZoomAdvanced1h
  • Your skills and agents reviewed against the standard
  • Next improvements and what to share with others
  • 30-day check briefing
